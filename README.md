# miniguia-frontend-automacao
Escolhi "Front-End e Automação" pois o futuro do dev web une interfaces rápidas (Micro Frontends) a integrações ágeis (n8n). O objetivo deste Miniguia é criar um "segundo cérebro" prático. Ele documenta arquiteturas e fluxos modernos, servindo como base de consulta rápida para tomar decisões técnicas mais inteligentes.
